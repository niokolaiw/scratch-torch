# Scratch Torch — pandas × torch × sklearn из кубиков 🤖

Расширение для **TurboWarp**, в котором нейросеть собирается из вложенных
кубиков-слоёв (сама стопка блоков = архитектура), а на сцене рисуется живая
схема сети со всеми связями: толщина ребра ∝ модуль веса после обучения,
плюс график loss.

- **данные** — блоки в стиле pandas (`создай DataFrame`, `колонка`, `нормализуй`, `раздели`),
- **слои** — блоки в стиле torch (`nn.Dense`, `nn.Dropout`, `nn.LSTM`, `nn.Conv2d`, …),
- **обучение** — в стиле sklearn (`обучи`/fit, `предскажи`/predict, `метрика`/score).

Внутри — настоящий **tensorflow.js** (без сервера, всё в браузере).

---

## Как запустить

Официальный Scratch произвольные расширения не грузит, поэтому нужен TurboWarp.

1. Захости файл `scratch-torch.js` по публичному URL
   (GitHub Pages, gist, любой статик-хостинг). Для локальной разработки:

   ```bash
   cd scratch-torch
   python3 -m http.server 8000
   ```

2. Открой редактор с расширением:

   ```
   https://turbowarp.org/editor?extension=http://localhost:8000/scratch-torch.js
   ```
   (или свой URL вместо `http://localhost:8000/`)

3. Демо-проект `demo-torch.sb3`:
   **File → Load from your computer**. Он сам: создаёт DataFrame из ирисов,
   собирает `Sequential(Dense 8 → Dense 3)`, обучает, предсказывает вид
   цветка и считает метрику. Данные для копирования — в `iris.csv`.

> Нужен интернет: tensorflow.js подтягивается с CDN при первом запуске.

## Блоки

### Данные (pandas 🐼, синие)
| Блок | Что делает |
|---|---|
| `создай DataFrame [имя] из [csv] разделитель [sep]` | парсит текст: первая строка = заголовки колонок |
| `колонка [col] из [table]` | репортёр-список со значениями колонки |
| `строк в [table]` | число строк |
| `нормализуй [table] способом [method] → сохрани как [newName]` | min-max или z-score |
| `раздели [table] на [train] и [test] тестовая доля [frac]` | перемешанный сплит |
| `покажи таблицу [table]` | рисует таблицу поверх сцены |

### Слои (torch 🔥, оранжевые) — вкладываются друг в друга!
```
модель m1 = Sequential( [ nn.Dense 16 relu → [ nn.Dense 3 softmax ] ] )
```
Последний аргумент слоя — `→ [next]` — принимает следующий слой, поэтому
**степень вложенности = архитектура**. Слои: `nn.Dense`, `nn.Dropout`,
`nn.Flatten`, `nn.LSTM`, `nn.Conv2d`, `nn.MaxPool2d`, `nn.Reshape`.

### Обучение (sklearn 🌲, зелёные)
| Блок | Что делает |
|---|---|
| `обучи [model] на [table] признаки [features] метка [label] эпох [n] батч [b] loss [..] оптимизатор [..]` | **fit**. Признаки через запятую (`x1,x2`) или `*` = все кроме метки |
| `предскажи [model] для [вход]` | predict. Вход — числа через запятую в **исходных единицах** |
| `метрика [model] на [table] признаки [..] метка [..]` | accuracy (классы) или R² (регрессия) |
| `последний loss модели [model]` | последнее значение loss |

`fit` **сам нормализует** признаки и метку и запоминает скейлеры — поэтому
`predict`/`метрика` принимают значения в исходных единицах, ничего вручную
нормализовать не надо.

### Визуализация (фиолетовые)
| Блок | Что делает |
|---|---|
| `нарисуй схему [model]` / `спрячь схему [model]` | рисует/убирает сеть на сцене |
| `сбрось всё` | стирает все таблицы и модели |

Схема обновляется во время обучения (график loss в углу) и при предсказании
(вход подсвечивается зелёным/красным по знаку значения).

## Устройство проекта

```
scratch-torch.js        — само расширение (TurboWarp custom extension)
demo-torch.sb3          — готовый демо-проект (генерируется make-demo-sb3.py)
iris.csv             — данные ирисов Фишера для копирования в блок
make-demo-sb3.py     — генератор demo-torch.sb3
tests/               — тесты (см. ниже)
```

## Тесты

Нужен Node.js ≥ 18 (tf.js для e2e скачается сам в `os.tmpdir()`).

```bash
node --check scratch-torch.js
npm run test          # логика (мок) + e2e с настоящим tensorflow.js
```

- `tests/harness.js` — мок-тесты блоков: CSV, сплит, нормализация, цепочки слоёв.
- `tests/e2e.js` — полный цикл на настоящем tf.js: регрессия (R²), классификация (accuracy), LSTM.
- `tests/sb3-verify.js` — проверяет, что `demo-torch.sb3` валиден: грузится настоящим
  scratch-vm. Требует `npm install` один раз (зависимости уже в package.json).
- `tests/tf-mini-test.js` — минимальный smoke-тест tf.js в node-шиме.

## Известные ограничения (честно)

- Официальный Scratch не работает — только TurboWarp (и ему подобные форки).
- LSTM/Conv2d требуют, чтобы первый слой был `nn.Reshape`/`nn.Conv2d`
  (вход решэпится автоматически, но продуктов входных чисел должен сходиться).
- 2D-изображения не поддерживаются — вход всегда одномерный вектор чисел.
- tf.js тянется с CDN — без интернета расширение не соберётся.
- Обучать нейросеть в Scratch — примерно так же медленно, как и положено 😄
